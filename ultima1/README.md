# Ultima 1

Tools for *Ultima I: The First Age of Darkness* (Origin Systems, 1986 PC
remake), GOG Galaxy release.

| Tool | Description |
|------|-------------|
| [save-manager](save-manager/) | Back up and restore characters, with stats shown (GUI + command line). |
| [maps](maps/) | Interactive overworld map in your browser: every place named, where your characters are, town layouts and notes. Also exports the maps to PNG. |

## Reference card

[reference-card.html](reference-card.html) is a one-page command reference card,
like the ones the old boxed games came with. Open it in a browser, or print it
(it fits on one letter page). Its contents come from the game's own text.
