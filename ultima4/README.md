# Ultima 4

Tools for *Ultima IV: Quest of the Avatar* (Origin Systems, 1985), GOG Galaxy release.

| Tool | Description |
|------|-------------|
| [save-manager](save-manager/) | Back up and restore your game, with a full party sheet (GUI + command line). |
| [maps](maps/) | Interactive world map in your browser, with town layouts, your party and notes. Anything that could spoil the game stays hidden until you turn it on. |

## Reference card

[reference-card.html](reference-card.html) is a two-sided reference card, like the ones the old boxed
games came with: commands and how to get started on one side, magic and travel on the other. Open it in
a browser, or print it (it fits two letter pages). It's spoiler-free: it comes from the game's manual,
without the hints section at the end of `ULTIMA4.TXT`, which gives away everything including the final
solution. Spell costs are from `AVATAR.EXE`.

The READMEs in these folders describe the game's file formats, and the maps one gets into
what's hidden and how it works. If you want to discover things in game, stick to their
usage sections.
